Version 1.49 brings MP3 and M4B into the same library and gets book covers on screen sooner. Open a series and its books now show their covers, ratings and status without having to open each book first.

### What's new since 1.48

- **M4B support.** Scan, tag and rename unencrypted M4B audiobooks alongside MP3s. Editing metadata and cover art preserves the audio and existing M4B chapter names and timings. Narrator tags take priority; older files can use Composer as a fallback.
- **Separate libraries.** Switch between collections with their own folders, history, ratings, settings and backups. Set genre counts per library or series: exactly, at least, at most, between, or no rule. Customize which badges appear, including Goodreads, Audible and your own Reviewed flag.
- **Precise ratings.** Type a rating such as `3.61` in **Edit Metadata** and see fractional stars plus the number. Series average the books you rated; writers average their rated series. You can sort writers by rating or hide or move the rating badge.
- **Listening statistics.** A dedicated workspace has Listening, History, Collection and Year recap views. Explore completed listens, relistens, audio hours, favorites, ratings and missing books. Find books by genre or release year. Record where and when you bought a book in the editor.
- **Faster browsing.** The visible series covers load first, in the background. Book Details reuses prepared artwork when it is still current. Unchanged rescans avoid rewriting the index, and opening a known book no longer writes unchanged history.
- **Safer changes.** Saving shows progress and verifies the embedded cover. A missing file can keep its listening history, or you can remove its saved entry. The separate option to move an existing audio file to Trash starts unchecked each time.
- **Local diagnostics.** Export OS, Flatpak and app versions and timing for scans, artwork and book opening under **Settings → Diagnostics**. Reports leave out file paths, book titles and listening history.

### Install or upgrade

This is a Linux **source release**. Download **Source code (zip)** or **Source code (tar.gz)** below, extract it, and open a terminal in the folder containing `pyproject.toml`. Close the running app before upgrading. With Flatpak and flatpak-builder installed:

```bash
flatpak remote-add --user --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak-builder --user --install --install-deps-from=flathub --force-clean \
  build-dir io.github.kibasnowpaw.AudiobookShelfManager.json
flatpak run --user io.github.kibasnowpaw.AudiobookShelfManager
```

Existing installations using this Flatpak ID keep their data. **Settings → Backups** lets you make a backup before upgrading. The collection manager does not play audiobooks or open DRM-protected files.
